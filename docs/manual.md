# Pictorial manual

The manual is generated from the committed CAD snapshot and the project's assembly
files by the `mechanical-docs` pipeline and copied here by `assembly/publish_manual.py`.
It is a draft inventory and inspection document: it does not assert fasteners,
quantities to buy or an assembly order.

- **Open:** [manual/index.html](manual/index.html)
- **Print:** [compact PDF, 36 pages](manual/free-standing-enclosure-991056-inventory.pdf) ·
  [appendix PDF, 53 pages](manual/free-standing-enclosure-991056-inventory-appendix.pdf)
- **Provenance:** [SOURCE.json](manual/SOURCE.json) (input hashes, PDF hashes, evidence run),
  [build-receipt.json](manual/build-receipt.json), [check-report.json](manual/check-report.json)

![Overview of the enclosure](manual/images/overview.png)

What is in it: picture-led parts cards with the CAD quantity and a blank count box; six
subassembly inspection views (caster, panel, toggle clamp, both frames, the main frame);
sixteen joint close-ups, each listing the hardware still to review at that joint; the
supplementary items not modelled in CAD; the project note on the intended build change.
